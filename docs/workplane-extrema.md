# Direct working-plane minimum and maximum illuminance

`report-workplane-read --path <report.pdf> --page 21 --expected-header '<exact room/scene header>' --expected-surface WP1` / MCP `read_workplane_pdf` reads a selected English working-plane details/calculation-object page. It requires explicit room/scene and surface identity, the recognized table column order, perpendicular adaptive illuminance basis, one unambiguous selected row and unambiguous height/wall-zone evidence.

The result retains average perpendicular illuminance, **direct reported Emin and Emax**, and numeric Uo when present, each with the PDF hash, selected page and surface ID. A dash uniformity is unavailable, never zero. It rejects mismatched room/surface, duplicate rows, unknown bases, missing geometry, invalid ranges and unsupported table layouts. It does not derive Emin by multiplying the rounded average and uniformity. It also does not authenticate report origin, prove freshness or infer that a workplane is a normal-desk-work task area. Orientation, applicable task conditions and rule adoption remain explicit review inputs.

The separate Hong Kong Labour Department advisory profile requires its stated applicability evidence; successfully reading a minimum is not permission to apply that profile universally. The original Summary reader still extracts only its supported summary metrics. Do not combine duplicate average/Uo records from both adapters into one evaluation input; select one evidence source per metric and calculation surface.
